# Orbyte MessagePilot — Sample Messages + AI Reply Editor

Starts with ten simulated messages across urgent, important, normal and low priorities. The inbox includes a **Normal & low** filter, and opens with a non-urgent message selected. The detail panel includes a suggested reply and editable draft. Approval/rejection is simulated; no real message is sent. Click **Add sample** to add more.

This standalone demo does not use an API. It is a training simulation and cannot send real messages. Assignment, approval and completion are simulated in the current browser session and reset when the page is refreshed.
